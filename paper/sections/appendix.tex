\section{Reproducibility}\label{app:repro}
All code, configuration files, and per-CVE predictions are in the project repository, the NVD snapshot is pinned to FKIE release \texttt{v2026.10.05-000016}, and each step below is a single command that regenerates its part of the paper.
\begin{itemize}\itemsep0pt
  \item Data preparation with \texttt{download\_data.py} and \texttt{prepare\_splits.py}.
  \item TF-IDF baselines with \texttt{baselines\_classical.py}.
  \item LoRA training with \texttt{mlx\_lm.lora} and \texttt{scripts/lora\_phi35.yaml}.
  \item Checkpoint selection with \texttt{select\_checkpoint.py}.
  \item Evaluation with \texttt{evaluate\_lora.py}.
  \item Tables, figures, and numbers in the text with \texttt{make\_tables.py} and \texttt{plot\_results.py}.
\end{itemize}
