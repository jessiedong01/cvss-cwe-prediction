\section{Reproducibility}\label{app:repro}
All code, configuration files, and per-CVE predictions are in the project repository.
The NVD snapshot is pinned to FKIE release \texttt{v2026.10.05-000016}.
Each step below is one command and regenerates its part of the paper:
\begin{itemize}\itemsep0pt
  \item data: \texttt{download\_data.py}, \texttt{prepare\_splits.py};
  \item TF-IDF baselines: \texttt{baselines\_classical.py};
  \item LoRA training: \texttt{mlx\_lm.lora} with \texttt{scripts/lora\_phi35.yaml};
  \item checkpoint selection: \texttt{select\_checkpoint.py};
  \item evaluation: \texttt{evaluate\_lora.py};
  \item tables, figures, and every number in the text: \texttt{make\_tables.py}, \texttt{plot\_results.py}.
\end{itemize}
