Until April 2026, the National Vulnerability Database (NVD) included a Common Vulnerability Scoring System (CVSS) vector, severity tier (Low, Medium, High, or Critical) and a Common Weakness Enumeration (CWE) vulnerability type for almost every CVE.
After April 2026, NIST started enriching only high priority vulnerabilities, and the overwhelming majority of new CVEs now appear without this information.
We consider the task of enriching new CVEs by predicting this information: given a CVE description, predict its CVSS v3.1 base metrics, CVSS score, severity, and CWE type.
